# SQL Analytics & Database Practice Hub

This repository helps you practice SQL logic using various schemas. It includes mock data for analytical simulations.

## 📁 File Structure

* `schema.sql`: Contains the database blueprints, table structures, and relationships.
* `seed_data.sql`: Contains large mock datasets for testing analytical queries.

## 📊 Case Studies

This repository combines 8 different real-world case studies:

1. **Auto Show**: Analyzes car performance and event participation.
2. **Average Salary**: Analyzes salary distribution and department structures.
3. **Student Scores**: Segments academic performance across different classes.
4. **Manager Sales**: Uses self-joins to map internal management hierarchies.
5. **Movie Genres**: Maps many-to-many relationships between movies and genres.
6. **Student Rankings**: Uses window functions to track university rankings.
7. **Welfare**: Practices NULL data handling and annual donation aggregation.
8. **Family Tree**: Queries family relationships based on parent data.

## 🚀 How to Use

1. Create a new database in your local SQL tool.
2. Run the `schema.sql` script to build the tables.
3. Run the `seed.sql` script to insert the practice data.
4. Use the Continue.dev extension in VS Code to practice.
